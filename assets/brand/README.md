# Diovandi brand assets

Monolith 1B (Curved), traced from `references/monolith-1b-reference.png`.
All variants are drawn from one master path.

| File | Use |
|---|---|
| `logos/primary/diovandi-mark.svg` | Master symbol, Midnight Navy, transparent, tight bounds |
| `logos/primary/diovandi-mark-small.svg` | Heavier-stem master for 48 px and below (favicons, nav) |
| `logos/primary/diovandi-mark-tile.svg` | Navy on Off-White square with 20% clear space |
| `logos/reversed/diovandi-mark-reversed.svg` | Off-White on Midnight Navy square |
| `logos/reversed/diovandi-mark-offwhite.svg` | Off-White symbol, transparent, for navy backgrounds |
| `logos/reversed/diovandi-mark-knockout.svg` | Navy square with the symbol cut out (transparent) |
| `logos/monochrome/diovandi-mark-black.svg`, `-white.svg` | Print, embossing, engraving |
| `logos/favicon/diovandi-favicon.svg` | Rounded navy tile, small master |
| `logos/favicon/diovandi-app-icon.svg` | Full-bleed navy tile for app icons and avatars |
| `lockups/diovandi-horizontal*.svg` | Symbol left of the Lora SemiBold wordmark (outlined) |
| `lockups/diovandi-stacked*.svg` | Symbol centred above the wordmark |
| `png/` | Transparent PNG exports |

Colours: Midnight Navy `#0B1F3B`, Aerospace Blue `#2E6BFF`, Titanium Gray `#8A94A6`,
Off-White `#FAF9F6`. Clear space: 20% of the symbol width on every side.

The Plus Jakarta Sans Lancip wordmark is not included yet: the Google Fonts build
of Plus Jakarta Sans has no stylistic sets, so it needs the Fontshare font files.
